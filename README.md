# 🧠 Web Development Quiz App

An interactive **Education & Assessment Tool** built with **HTML, CSS, and JavaScript**.  
Users can test their web development knowledge across **Beginner**, **Intermediate**, and **Advanced** levels with a modern 3D UI and learning feedback after each quiz.

---

## 🚀 Features

- 🎯 **Three difficulty levels**
  - Beginner
  - Intermediate
  - Advanced
- 📊 **Progress bar** showing quiz completion
- 🧩 **Multiple-choice questions**
- 📚 **Learning/Wiki explanations** after quiz completion
- 💎 **Modern 3D card UI** with animations
- 🔁 **Restart & replay** functionality
- ⚡ **Pure Vanilla JS** (no frameworks)

---

## 🛠️ Technologies Used

- **HTML5** – Structure
- **CSS3** – Styling, 3D effects, animations
- **JavaScript (ES6)** – Quiz logic & interactivity

---

## 🧩 How It Works

1. User selects a **difficulty level**
2. Questions are loaded dynamically from a question database
3. Progress bar updates as the quiz advances
4. Score is calculated in real-time
5. After finishing:
   - Final score is shown
   - Learning explanations are displayed for each question
6. User can restart and try another level
